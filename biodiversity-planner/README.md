# Biodiversity Native Planting Planner

A web application that recommends native plants based on a user's location, weather conditions, and gardening preferences to promote biodiversity and support local pollinators.

## Problem Statement

Urban gardeners often struggle to identify native plants suitable for their local climate and environment. This project provides personalized recommendations to encourage biodiversity and sustainable gardening.

## Features

- 🌱 Native plant recommendations
- 🌦 Weather-aware suggestions
- 🐝 Pollinator information
- 📍 Location-based recommendations
- 📊 Biodiversity score
